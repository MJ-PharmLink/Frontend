# AI 도우미 '소리' 사용 가이드

PharmLink ERP 화면 어디에서나 오른쪽 아래 **말풍선 버튼**을 누르면 AI 도우미가 열립니다.
재고 수치를 자연어로 물어보면 실제 ERP 데이터를 조회해 답합니다.

> 화면 캡처(모의 데이터)는 레포의 Git LFS 업로드가 막혀 있어 프로젝트 공유 폴더 `chatbot/images/` 에 따로 두었습니다: `chat-empty.jpg`, `chat-answer-card.jpg`, `chat-errors.jpg`, `chat-mobile.jpg`.

## 무엇을 물어볼 수 있나요

| 유형 | 이렇게 물어보세요 | 답변에 나오는 것 |
|---|---|---|
| 부족 재고 | "지금 재고가 부족한 상품 알려줘", "1번 창고 부족 재고만 보여줘" | 안전재고 이하 상품, 현재 재고, 부족 수량 |
| 상품 재고 검색 | "타이레놀 재고 얼마나 있어?", "상품코드 AN-0001 재고" | 상품별·창고별 수량과 재고 상태 |
| 창고별 재고 | "2번 창고 재고 목록 보여줘" | 해당 창고 재고 목록(10건씩) |
| 유통기한 | "30일 안에 유통기한 끝나는 재고 알려줘" | *(백엔드 기능 추가 후 제공)* |
| 사용 방법 | "재고 조정은 어떻게 해?" | ERP 화면 사용 안내 |

**할 수 없는 것**: 재고 수정, 주문 승인, 상품 삭제 같은 데이터 변경. 소리는 조회 전용입니다.

## 답변 카드 읽는 법

1. **배지**: 어떤 조회를 했는지(부족 재고 · 재고 조회 · 유통기한 · 일반 안내). 결과가 없으면 '결과 없음'이 함께 붙습니다.
2. **본문**: AI가 정리한 답변. 표가 있으면 표로 보여줍니다.
3. **조회 조건**: 실제로 조회한 창고, 검색어, 결과 건수, 페이지.
4. **근거 데이터 보기**: AI 답변의 근거가 된 원본 행을 표로 펼칩니다. 숫자가 의심되면 여기서 확인하세요.
5. **대시보드/재고 관리에서 보기**: 같은 데이터를 ERP 화면에서 바로 엽니다. **복사**는 답변 본문을 클립보드에 담습니다.

## 입력 팁

- **Enter** 전송, **Shift+Enter** 줄바꿈. 질문은 1000자까지 입력할 수 있습니다.
- 상품명·상품코드·창고 번호를 넣으면 더 정확합니다. ("1번 창고", "AN-0001")
- 화면을 이동해도 대화가 유지됩니다. 새로 시작하려면 상단의 **새 대화**를 누르세요. 로그아웃하면 대화가 지워집니다.
- 직전 대화 10개까지 함께 보내므로 "다음 페이지"처럼 이어서 물어볼 수 있습니다. *(백엔드 반영 후)*

## 오류가 나면

| 메시지 | 의미 | 할 일 |
|---|---|---|
| ERP 데이터를 조회하고 답변을 만드는 중이에요 (N초) | 정상 처리 중 | 기다리거나 **취소** |
| 응답 시간이 초과되었어요 | 95초 안에 답이 오지 않음 | 질문을 더 구체적으로 바꿔 **다시 시도** |
| AI 서비스가 잠시 응답하지 않아요 | Gemini 일시 장애 | 잠시 후 **다시 시도**, 급하면 재고 관리 화면 이용 |
| 데이터를 조회하지 못했어요 | 서버 조회 오류 | **다시 시도**, 반복되면 담당자에게 오류 코드 전달 |
| 조회 권한이 없어요 / 비활성화된 계정이에요 | 403 | 관리자에게 권한·계정 상태 확인 요청 |
| 로그인이 필요해요 | 로그인 만료 | 자동으로 로그인 화면으로 이동, 다시 로그인 |
| 서버에 연결할 수 없어요 | 네트워크·서버 중단 | 연결 확인 후 다시 시도 |

오류 메시지 오른쪽 아래의 작은 코드(예: `503 AI_SERVICE_UNAVAILABLE`)를 담당자에게 알려 주면 원인을 빨리 찾을 수 있습니다.

## 주의

- AI 답변은 조회 시점의 데이터를 요약한 것입니다. 발주·출고 같은 결정 전에는 **근거 데이터** 또는 재고 관리 화면에서 수치를 한 번 더 확인하세요.
- 개인정보나 비밀번호를 질문에 넣지 마세요.

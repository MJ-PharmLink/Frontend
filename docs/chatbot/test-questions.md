## 화면(UI)에서 함께 볼 점

| 상황 | 기대 화면 |
|---|---|
| 답변 대기 | 스피너와 경과 초. 12초가 지나면 '평소보다 오래 걸리고 있어요' 안내와 취소 버튼 |
| 35초 초과 (화면 제한 시간) | '응답 시간이 초과되었어요' + 다시 시도 |
| 504 `AI_TIMEOUT` (서버 Gemini 시간 초과, 운영 CloudFront 30초 초과) | 'AI 응답이 늦어지고 있어요' + 다시 시도 |
| 429 `AI_RATE_LIMITED` | 'AI 호출 한도를 넘었어요' + 다시 시도 |
| 503 `AI_SERVICE_UNAVAILABLE` (Gemini 장애, 서버에 키 없음) | 'AI 서비스가 잠시 응답하지 않아요' + 다시 시도 |
| 401 | 토큰 재발급을 한 번 시도. 실패하면 로그인 화면으로 이동 |
| 403 `FORBIDDEN` / `ACCOUNT_DISABLED` | '조회 권한이 없어요' / '비활성화된 계정이에요' (다시 시도 없음) |
| 빈 결과 | '결과 없음' 배지 (`query_context.total_count` = 0 또는 answer 빈 값) |
| 1000자 초과 | 글자 수 빨간색, 보내기 비활성 |
| 한글 입력 중 Enter | 조합 중에는 전송하지 않음 |
| 2000자 넘는 긴 답변 뒤 다음 질문 | 정상 전송 (history는 2000자로 잘라 보냄) |

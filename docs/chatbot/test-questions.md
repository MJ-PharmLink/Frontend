## 화면(UI)에서 함께 볼 점

| 상황 | 기대 화면 |
|---|---|
| 답변 대기 | 말풍선에 스피너와 경과 초. 12초가 지나면 '평소보다 오래 걸리고 있어요' 안내와 취소 버튼 |
| 95초 초과 | '응답 시간이 초과되었어요' + 다시 시도 (서버 Gemini 읽기 제한 45초 × 최대 2회 기준) |
| 503 AI_SERVICE_UNAVAILABLE | 'AI 서비스가 잠시 응답하지 않아요' + 다시 시도 |
| 401 | 토큰 재발급을 한 번 시도. 실패하면 로그인 화면으로 이동 |
| 403 FORBIDDEN / ACCOUNT_DISABLED | '조회 권한이 없어요' / '비활성화된 계정이에요' (다시 시도 버튼 없음) |
| 빈 결과 | 카드에 '결과 없음' 배지 (서버가 query_context.total_count=0 을 주거나 answer가 비었을 때) |
| 1000자 초과 | 글자 수가 빨간색, 보내기 버튼 비활성 |
| 한글 입력 중 Enter | 조합 중에는 전송하지 않음 |
